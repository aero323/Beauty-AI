# SalesBoost AI 管理后台

SalesBoost AI 管理后台是一个面向培训、内容和组织管理的 Web 应用，当前版本聚焦课件生成、课件管理、数字人顾客、场景剧本、产品金句、考试管理和任务分发。

## 当前模块

- 仪表盘：不同角色视角的管理首页。
- 组织与人员：组织视图、门店档案、人员档案、用户管理。
- 课件体系：课件生成、课件管理、区域课件管理。
- 陪练资产：数字人顾客、场景剧本、产品金句。
- 考试体系：试卷生成、题库、附加题、考试管理、考试任务。
- 学习与练习任务：学习任务管理、练习任务管理。
- 配置类能力：分类管理、通知设置、知识图谱。

## 版本更新说明

### 2026-07-14 题库题型与考试结果分析增强版

本版本把题库、组卷、考试下发和成绩复核链路继续往“可演示、可落后端”的方向推进，重点补齐新题型、随卷信息采集、岗位差异化及格线、成绩单导出和洞察分析。

#### 题库与生成题目

- 题库题型从单选、多选、判断、段落题继续扩展，新增下拉题、排序题、复选网格和文件上传题。
- 段落题用于回答者输入一段主观答案，保留参考答案、评分要点和 AI 阅卷提示字段。
- 下拉题复用选项与单答案结构，适合在 APP 端用下拉框完成单选式选择。
- 排序题支持维护多个步骤选项和正确顺序，可用于护肤步骤、客户服务流程、销售流程等场景。
- 复选网格支持维护行、列和正确匹配关系，可用于成分与功效、产品与肤质、场景与话术等矩阵题。
- 文件上传题支持设置上传说明、允许图片/视频类型、评分要点和 AI 阅卷提示，适合收集演示视频、陈列照片、实操图片等材料。
- 题库编辑抽屉和生成题目待审核预览都支持题目素材，培训师可以为题目补充图片或视频；当前前端使用本地对象 URL mock，后续可替换为真实文件上传/OSS 地址。
- `QuestionBankItem` 统一扩展了 `gridRows`、`gridColumns`、`gridCorrectAnswers`、`uploadInstructions`、`allowedUploadTypes`、`attachments` 等字段，新题型在题库、生成预览、AI 派生和搜索中共用同一套结构。
- 生成题目页的 AI 预览支持直接切换题型，预览卡片会随题型显示对应编辑控件；审核导入题库前仍需人工确认。
- 题库搜索覆盖新题型的题干、选项、网格行列、上传说明、素材名称、素材链接、标签、产品线、品牌、类别、来源文件等内容。

#### 题库分类、标签与筛选

- 题库左侧筛选树改为多选确认式筛选，支持按品牌、产品线、类别和通用能力组合筛选。
- 品牌筛选包含 Y.O.U、Dazzle Me、BNB、Lavojoy、Hued、Glam Fix。
- 产品线筛选包含护肤品、彩妆、护发、化妆品。
- 类别筛选包含粉底、气垫、唇釉、精华、洁面。
- 通用能力用于承载服务礼仪、色彩搭配、沟通开场等不直接归属某条产品线的题目。
- 筛选树分组支持折叠，底部“清空 / 确定”按钮固定展示，避免筛选项较多时按钮被滚动遮挡。
- 常用标签管理保持一套标签库，不再拆分系统标签和自定义标签；AI 生成题目优先从现有标签库匹配，若生成新标签，则在审核入库时同步加入常用标签库。
- 标签管理弹窗以大题库场景为目标，使用密集表格、搜索、排序、分页、行内改名和删除，适配成百上千标签的治理方式。

#### 考试组卷与发布

- 发布考试时支持按参加考试的角色/岗位设置不同及格分数。
- 岗位及格分数以“左侧角色下拉 + 右侧分数下拉”的方式维护，可添加多条条件。
- 默认角色包括初级 BA、高级 BA、店长、区域经理、区域培训师、区域培训师主管，及格分可在 60 到 100 之间按 5 分步进选择。
- 每次考试下发时，系统默认把两道固定信息题追加到试卷最后：
  - 请填写你的职位名称。
  - 请填写你的门店渠道。
- 两道固定信息题不进入题库、不允许培训师删除、不计分，只用于后续成绩统计和组织分析。
- 组卷页会在已选题目列表末尾展示这两道固定信息题，并在发布弹窗与发布成功弹窗中提示“固定信息题 2 道”。
- 发布后的考试任务会携带岗位及格线、固定信息题定义和试卷总题数，任务卡片中可看到对应信息。

#### 考试任务管理与成绩复核

- 已结束考试的“完整考卷与成绩单”弹窗扩展成绩列表字段：工号、姓名、地区、职位、门店、门店渠道、最终得分、及格分、是否及格、操作。
- 成绩单搜索支持姓名、工号、地区、职位、门店和门店渠道。
- 是否及格按考生职位匹配发布时配置的岗位及格线；如果没有匹配到职位规则，则回退默认及格线。
- 成绩列表支持导出 Excel。当前前端使用浏览器原生生成 `.xls` 文件，不额外引入依赖，Excel 可直接打开。
- 导出的 Excel 包含三块内容：
  - 成绩明细：包含地区、职位、门店、门店渠道、最终得分、及格分数和是否及格。
  - 成绩分布直方图：按 0-59、60-69、70-79、80-89、90-100 统计人数和占比，并用文本条形图表示分布。
  - 不同职位通过率：按职位统计参考人数、及格人数、岗位及格分数和通过率。
- 考试结果洞察弹窗新增成绩分布直方图，使用 Recharts 展示本次考试最终得分区间人数分布。
- 考试结果洞察弹窗新增不同职位通过率卡片，按职位分别展示及格线、通过率、及格人数和参考人数。
- 已结束考试 mock 数据补充多岗位及格线，用于演示不同职位不同通过标准：初级 BA 80 分，高级 BA 85 分，店长 90 分，区域培训师 90 分。

#### 看板、积分与陪练配置

- 新增积分计算工具 `src/lib/points.ts`，统一员工当月积分口径：`当月积分 = 已完成任务数 x 10 + 考试成绩`。
- 新增当月积分和门店积分说明组件，hover 后展示积分计算公式、任务完成分、考试成绩计入口径和月底冻结归档说明。
- 总部、区域、门店和人员相关看板继续使用统一积分口径，避免不同页面对积分计算出现不一致表达。
- 新增 AI 陪练提示词说明组件，提示培训师填写角色背景、场景流程、回答提示和金句使用提示会影响最终陪练效果。
- 数字人顾客、场景剧本、区域场景剧本、金句库等配置页补充提示词填写提醒，帮助培训师理解输入内容与学员端对话稳定性的关系。

#### 三语和交互文案

- 补齐本轮新增 UI 的中文、英文、印尼语文案，包括新题型、题目素材、网格题、文件上传题、固定信息题、岗位及格分数、成绩单字段、导出 Excel、成绩分布直方图和不同职位通过率。
- 题干、业务内容、文件名、标签名等仍通过 `data-i18n-skip` 保持不翻译，避免培训师录入内容被误翻译。

### 2026-07-07 题库治理体验修正版

- 题库状态流转补齐研发注释：手动录入题走“草稿 -> 已入库 -> 已归档”，AI 派生题走“待审核 -> 已入库 -> 已归档”，明确草稿和待审核题不会进入考试组卷或课件附加题候选。
- AI 旧题派生题增加生成进度反馈，生成过程中展示读取旧题、生成变体、继承分类标签和查重写入待审核等步骤，避免用户误以为点击后无响应。
- 题目列表题干支持 hover/title 查看完整题目，列表仍保持单行扫描效率。
- 分类体系新增“通用能力”顶层分类，用于承载礼仪、沟通开场、色彩搭配等不直接归属产品线的题目，后续细分交给培训师用标签管理。
- 标签体系收敛为一套“常用标签”，取消系统标签/自定义标签的产品表达；AI 生成题目优先从现有常用标签中匹配，审核入库时才把新标签同步加入常用标签库，同名自动去重。
- 常用标签增加“标签管理”弹窗，支持搜索、排序、新增、改名、删除；删除标签只解除题目关联，不删除题目。
- 标签管理弹窗改为适配大题库的密集表格，一页展示 60 个标签，去掉说明卡和统计卡，保留搜索、排序、行内改名/删除和分页信息，便于后续接服务端分页。
- 新增每题最多 5 个标签的前端约束，批量加标签、AI 派生标签和手动编辑标签都按同一规则去重和截断。

### 2026-07-06 题库资产治理增强版

- 题库升级为共享题目资产库，统一题目数据模型，题库管理、生成题目、考试组卷和课件附加题都读取同一份题库状态。
- 题库管理页新增产品线/产品分类树、标签筛选、题型/难度/状态过滤和关键词搜索，支持按全局品类体系检索题目。
- 题目支持手动新增、二次编辑、自定义标签、批量标签、归档、重复题处理，并新增多选题和简答题配置能力。
- AI 旧题派生题支持从单题或批量选择生成变体，新题默认进入“待审核”，培训师确认题干、答案、标签和分类后再审核入库。
- 生成题目页的 AI 结果改为可编辑待审核预览，确认后再导入题库；已入库题目可直接用于考试组卷和课件附加题。

## 本地运行

1. 安装依赖

```bash
npm install
```

2. 启动开发服务

```bash
npm run dev
```

默认端口是 `3000`。
