# BeautyAI 管理后台

BeautyAI 管理后台是一个面向培训、内容和组织管理的 Web 应用，当前版本聚焦课件生成、课件管理、数字人顾客、场景剧本、产品金句、考试管理和任务分发。

## 当前模块

- 仪表盘：不同角色视角的管理首页。
- 组织与人员：组织视图、门店档案、人员档案、用户管理。
- 课件体系：课件生成、课件管理、区域课件管理。
- 陪练资产：数字人顾客、场景剧本、产品金句。
- 考试体系：试卷生成、题库、作业、考试管理、考试任务。
- 学习与练习任务：学习任务管理、练习任务管理。
- 配置类能力：分类管理、通知设置、知识图谱。

## 版本更新说明

### 2026-05-08 后台评审反馈迭代版

- 课件管理支持从课件卡片直接进入课件编辑页，并保留从编辑页返回课件库的路径。
- 课件、剧本、产品金句等内容配置页补充 AI 一键生成入口，缺少基础信息时给出 toast 提醒。
- 保存产品库、保存剧本等关键操作增加保存成功 toast，减少操作反馈断点。
- 产品金句图片上传说明改为更贴近移动端培训头图的方图要求，并放宽大小限制以适配二次压缩。
- 统一项目内研发备注样式为深蓝色气泡和深蓝 hover 提示；重复列表内的研发备注只保留一个代表项，避免整页重复“注”标记。
- 首页通知、AI 自动洞察、任务查看弹窗等研发备注和交互说明补齐；任务弹窗改为更易读的单列布局。
- 课件、剧本、金句等 mock 数据中的不必要区域标识做了清理，避免总部视角出现错误的区域标签。
- AI 自动洞察补充每周离线聚合与 token 节省实现口径：先用结构化数据筛选 Top 候选，再把短样例交给模型总结。
- 新增区域培训师访谈与看板建模产品记录，用于后续验证区域培训师真实工作流和看板优先级。

### 2026-05-07 后台原型迭代版

- 全局品牌统一为 `BEAUTY AI`，移除旧的 Lumina / L'ÉCLAT 展示文案。
- 区域、总部、门店相关看板补充“当月积分”，与学员端学习积分口径保持一致。
- 任务监控标签拆分为“来源 + 任务类型”，例如“区域 + 考试任务”“区域 + 练习任务”。
- 高风险 BA 模块去掉过重的动作按钮和判断标签，保留基于登录、任务、考试、练习记录的风险提示。
- 员工学习详情里的练习数据统一为“练习”口径，去掉“陪练与打卡”“金句跟读连击”等不准确文案。
- 数字人顾客配置支持上传学员端使用的大图封面，并支持自定义剧本大纲或从已有场景剧本中选择。
- AI 课件生成页去掉“生成 AI 讲解”开关，保留讲解音色选择，并增加给研发的 minimax 印尼语音色列表提示。
- 产品笔记新增“自动数据统计与学习提示实现口径”，明确后端规则和数据聚合负责结论，LLM 最多负责表达。

## 本地运行

1. 安装依赖

```bash
npm install
```

2. 启动开发服务

```bash
npm run dev
```

默认端口是 `3000`。

## 技术栈

- React 19
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Recharts
