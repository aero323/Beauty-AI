# BeautyAI 管理后台

BeautyAI 管理后台是一个面向培训、内容和组织管理的 Web 应用，当前版本聚焦课件生成、课件管理、数字人顾客、场景剧本、产品金句、考试管理和任务分发。

## 当前模块

- 仪表盘：不同角色视角的管理首页。
- 组织与人员：组织视图、门店档案、人员档案、用户管理。
- 课件体系：课件生成、课件管理、区域课件管理。
- 陪练资产：数字人顾客、场景剧本、产品金句。
- 考试体系：试卷生成、题库、作业、考试管理、考试任务。
- 学习与练习任务：学习任务管理、练习任务管理。
- 配置类能力：分类管理、通知设置、知识图谱。

## 版本更新说明

### 2026-05-07 后台原型迭代版

- 全局品牌统一为 `BEAUTY AI`，移除旧的 Lumina / L'ÉCLAT 展示文案。
- 区域、总部、门店相关看板补充“当月积分”，与学员端学习积分口径保持一致。
- 任务监控标签拆分为“来源 + 任务类型”，例如“区域 + 考试任务”“区域 + 练习任务”。
- 高风险 BA 模块去掉过重的动作按钮和判断标签，保留基于登录、任务、考试、练习记录的风险提示。
- 员工学习详情里的练习数据统一为“练习”口径，去掉“陪练与打卡”“金句跟读连击”等不准确文案。
- 数字人顾客配置支持上传学员端使用的大图封面，并支持自定义剧本大纲或从已有场景剧本中选择。
- AI 课件生成页去掉“生成 AI 讲解”开关，保留讲解音色选择，并增加给研发的 minimax 印尼语音色列表提示。
- 产品笔记新增“自动数据统计与学习提示实现口径”，明确后端规则和数据聚合负责结论，LLM 最多负责表达。

## 本地运行

1. 安装依赖

```bash
npm install
```

2. 启动开发服务

```bash
npm run dev
```

默认端口是 `3000`。

## 技术栈

- React 19
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Recharts
