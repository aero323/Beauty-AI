# BeautyAI 管理后台

BeautyAI 管理后台是一个面向培训、内容和组织管理的 Web 应用，当前版本聚焦课件生成、课件管理、数字人顾客、场景剧本、产品金句、考试管理和任务分发。

## 当前模块

- 仪表盘：不同角色视角的管理首页。
- 组织与人员：组织视图、门店档案、人员档案、用户管理。
- 课件体系：课件生成、课件管理、区域课件管理。
- 陪练资产：数字人顾客、场景剧本、产品金句。
- 考试体系：试卷生成、题库、作业、考试管理、考试任务。
- 学习与练习任务：学习任务管理、练习任务管理。
- 配置类能力：分类管理、通知设置、知识图谱。

## 版本更新说明

### 2026-05-09 多语言与视觉体系迭代版

- 新增全局中文、英文、印尼语三语切换能力，入口位于顶部导航语言选择器，语言偏好会写入本地存储。

- 补齐人员档案、门店档案、学习任务、练习任务、考试组卷、题库、作业配置、全国/区域看板等页面的 UI 文案翻译；任务范围、分发对象、考试关联题数、审核发布步骤、AI 自动洞察等系统配置文案也纳入翻译。
- 针对英文和印尼语较长文案优化布局：侧栏标题、分段按钮、表格列宽、题型列、任务范围、按钮组和弹窗内容支持更灵活的换行与自适应宽度。
- 重做 BEAUTY AI 后台视觉体系，收敛过多高饱和色，统一为更柔和的玫瑰品牌色、暖灰底色、深色文本与克制的边框阴影。
- 调整品牌玫瑰色，避免与低分/危险/警告红色混淆；低分、撤回、停用等风险态统一使用明确红色语义。
- 新增 `visualTones` 视觉语义工具，统一进度、分数、任务状态、AI 操作按钮的颜色规则：高完成度偏绿，低完成度偏红，中间态偏琥珀或蓝色。
- 统一“进行中”“已完成”“待开始”“考试中”等任务状态标签样式；任务达标率、任务完成率、排行榜进度条、门店/人员档案进度都按完成度语义着色。
- 统一“AI 一键生成配图”“AI 一键生成剧本”“AI 一键生成金句”“AI 组卷”等 AI 操作按钮的视觉识别，减少和普通操作按钮混淆。
- 考试组卷发布成功后新增弹窗提示，引导到考试任务管理查看已发布任务；考试任务管理支持对待开始、考试中的考试执行“撤回考试”，并增加危险操作二次确认，撤回后任务从列表移除。
- 学习任务、练习任务的“停用任务”增加二次确认，避免误停用；新建任务、新建课件/剧本/数字人/产品等入口统一为左侧加号加“新建”的按钮形态。
- 调整全国/区域看板与档案页表格信息架构，将“当月积分”前移到“任务完成率”之前，保持积分和完成率的扫描顺序一致。
- 将看板中的“新增”入口统一为“查看”，点击后跳转对应管理页面，避免在总览页产生重复新建入口。
- AI 自动洞察文案补充英文/印尼语翻译，并保留给研发的离线聚合实现说明：每周扫描近 7-14 天聚合指标，先用 SQL/规则筛选候选，再把短样例交给模型总结以降低 token 消耗。
- 优秀标杆 TOP 3 补充研发备注：同分情况下按更早交卷排序。

## 本地运行

1. 安装依赖

```bash
npm install
```

2. 启动开发服务

```bash
npm run dev
```

默认端口是 `3000`。

- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
